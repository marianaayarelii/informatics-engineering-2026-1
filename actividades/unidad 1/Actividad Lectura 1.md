## Actividad 1: Comprensión conceptual (individual)

Objetivo: Verificar que el estudiante domina los conceptos fundamentales.

#Instrucciones

Despues de leer los archivos que están en el directorio de materiales. Responde brevemente (máx. 3–5 líneas por pregunta):

1.- ¿Cuál es la diferencia entre entrada y salida en un programa?
La entrada son los datos que el programa recibe para poder procesarlos, la salida es el resultado que el programa genera después de procesar la información

2.- ¿Por qué es importante declarar correctamente el tipo de una variable?
Porque el tipo de variable define qué tipo de datos puede almacenar y qué operaciones se pueden realizar con ella 

3.- Explica con tus palabras qué es una clase y qué es un método.
Una clase define las características y comportamientos de un objeto dentro de un programa. Un método es una función que pertenece a una clase y que permite realizar acciones o procesos utilizando los datos de esa clase

4.- ¿Qué problema resuelve el uso de packages?
Los packages permiten organizar el código en grupos o módulos relacionados. Esto ayuda a mantener el código ordenado, facilita su mantenimiento, evita conflictos entre nombres de clases y permite reutilizar componentes en diferentes proyectos

5.- Menciona dos reglas de estilo que mejoren la legibilidad del código.
- Usar nombres claros y descriptivos para variables, clases y métodos
- Mantener una correcta indentación y organización del código para que sea más fácil de leer
